# 図のファイルを使う方へ

初めて読む場合は、ファイルを編集せず[写真と図のHTML版](../画面から学ぶ_Giftia.html)を開いてください。

| ファイル | 何を表すか | 使い方 |
|---|---|---|
| er.mmd | DBの表どうしの関係 | どこに何を記録し、IDでどう結ぶかを読む。時間順の図ではない |
| 利用フロー.mmd | 作成から決定までの大きな道筋 | 利用者がどんな順で使うかを読む |
| シーケンス01〜06.mmd | 操作ごとの処理の順序を文字で記述 | Mermaidという図の記法に対応したエディターで再編集できる |
| シーケンス01〜06.svg | 上記の図を画像として保存 | ブラウザーで開いて拡大できる。画像にしても文字が荒れにくい形式 |

シーケンスは横の箱が担当、縦が時間、矢印が処理の依頼や結果です。01作成、02入室、03候補、04投票、05集計の画面内操作、06決定保存と再訪の順です。

実画面写真は別の[画面フォルダ](../画面/)に保存。FigJamには[編集可能な要約図](https://www.figma.com/board/cC7dJoFZmEweqYVAYn6Kh8)があります。画面や処理を変更したら、元の図と説明も対応させて更新してください。
