## 最新仕様の要点

- 新規ルームは開設者が最初の1品以上を公開し、その後に参加者も匿名で商品を追加し、ルーム全体で異なる商品を最大10品にまとめる。
- 候補提出期間の入室時に、贈る相手の「好み／避けたいもの／その他」を入力。情報がなければスキップできる。
- 主催者は投票前にルーム名・総予算・予定人数・受取期限を修正でき、入室コメントを参考に候補を追加・差し替え・除外し、手動で投票を開始する。
- 投票開始後は候補変更・コメント投稿を止め、全員が各商品に★1〜3で投票する。
- 主催者が1品または受取人が1品選ぶカタログを選択し、複数選択の決定理由とともに保存する。決済はデモ。

「主催者指定5人・1人3品・最大15品」「全員提出で自動開始」「商品別コメント」「相談欄の常設入力」は旧仕様です。商品レビュー★4以上と、参加者の投票★1〜3は別の値です。
