# 共通DBの商品読取を候補保存へ接続

2026-11-15。Issue #14-1（#16）。ブランチfeature/issue-16-shared-catalog、開始点7468299（お気に入り追加PR #15の先頭）。ユーザーの指示に従い、共通DBの商品を読む範囲まで接続した。共通DBの改修・書き込みは行っていない。

## 実装と設定

[接続仕様とファイル別解説](../shared-catalog.md)を追加。商品取得だけをproduct_catalog.pyへ分け、候補保存は既存SQLite、お気に入りは既存localStorageへ残す。既存main.py・database.py・searchGiftsは変更しない。

APIはGIFTIA_CATALOG_SOURCE=sharedを指定して127.0.0.1:8101で起動。既存の接続設定をuvicornのenv-fileでアプリ内部だけに渡した。資格情報は表示・コピー・編集していない。画面は127.0.0.1:3200からこのAPIへ接続する。設定値の誤りや接続失敗を架空商品へフォールバックさせない。
