# 普段の検索から送別用のお気に入りを保存

2026-11-15。Issue #12-1（#14）。ブランチ`feature/issue-14-farewell-favorites`。開始点はPR #13の`cae6164`。今回の依頼は、既存のルーム内検索・候補ストック・手掛かり入力を残したまま、普段の検索から保存した商品をルームで選べるようにする追加機能。

## 実装

トップ検索のカードの外側にお気に入り保存ボタン、一覧`/favorites/farewell`、ルーム内のお気に入りタブを追加。既存の検索関数・商品型・ResultCard・検索APIは変更していない。候補ストックは従来のAPIとSQLiteへ保存し、お気に入りだけをブラウザーのlocalStorageへ保存する。

お気に入りは3件以上を保存でき、ルームへコピーする商品と手掛かりの合計だけが最大3枠。コピー元のお気に入りは残る。お気に入り解除でコピー先を削除しない。共通MySQL・本人確認・端末間同期は追加していない。

仕様と各ファイルの役割は[追加契約](../farewell-favorites.md)を参照。
