## 3. 現在の進行状況（11/15 文書整理時点）

- ケースに出てくる顧客 A〜E の状況を整理した。
- そのうち **Aさん（送別）** と **Dさん（家族への誕生日）** をモデルにして議論した。
- 結論として、Aさんのような **「複数人で話し合って決めたい人たち」に向けたサイト改善** を掲げ、売上アップにつなげることにした。
  - 根拠：送別シーンはセッション構成比 18% に対して購入率 1.7%、平均閲覧商品数 16.5件、購入までの日数 5.3日（Exhibit 1 表2）。Aさんは同僚2人の同意を得てから購入している（Exhibit 2 Aさん）。
- 添付の第二弾（11/14更新）に合わせ、要求定義書・要件定義書のmd版を整理した。案B（根拠付きの相談相手）を中心に、共同決定と比較を組み合わせる。
- Phase1はLLMなし。実決済・実配送・集金・支払い記録・同世代の分析は対象外。一人あたり負担額は表示する。
- 受け取り期限は土日祝日を選択できない仕様。日本の祝日（振替休日・国民の休日を含む）に対応し、内閣府の公表済み2026・2027年の共通データで検証する。営業日の逆算方法は未確定。
- ルーム参加の具体的な仕様、営業日の計算、候補ストックと提出の区別などは未確定。要件定義書末尾を確認する。
- 最初のPoCとしてルーム作成・幹事同時登録・MySQL保存・再表示・負担額表示を実装し、PCとスマートフォンで確認した。参加操作・プロフィール等は未実装。
