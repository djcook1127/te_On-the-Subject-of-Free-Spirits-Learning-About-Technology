## 1. 背景と目的

### Giftia の現状（事実）

- 直近1年の年間セッション数は 375万 → 480万（前年比 28% 増）。一方、年間売上は 6.41億円 → 6.91億円で約 8% 増にとどまる（ケース本文、Exhibit 1 表1）
- 購入率は 3.6% → 3.0% に低下（Exhibit 1 表1）
- 1セッション当たり商品詳細閲覧数 6.2 → 9.4、商品詳細→カート投入率 12% → 8%、カート放棄率 34% → 41%、初回訪問から購入までの平均日数 1.8日 → 3.1日、複数セッションを経て購入した比率 38% → 56%（Exhibit 1 表1）
- 取り扱い商品数は3年間で約 5,000点 → 約 8,000点に増加（ケース本文）
- 原因について経営会議の意見は分かれている（商品部：品揃え不足ではない／マーケティング部：売れ筋商品の見せ方に改善余地／開発部：検索条件の追加／記事コンテンツを充実させるべきという意見）（ケース本文）

### 社長が解決したいこと

- 機能の話から始めず、Giftia を使っている人が何に困っているのかを明らかにし、優先して解決すべき顧客課題を定義すること（ケース本文）
- そのうえで、2か月後までに何を作るべきかを要求・要件にまとめ、一部を実装して確かめて提案すること（ケース本文）

### この施策の目的

【案】送別のように **複数人でお金を出し合い、話し合って贈り物を決める人たち** が、一緒に贈る人と納得して早く決められるようにする。それによって送別シーンの購入率（現状 1.7%）を引き上げ、Giftia 全体の売上向上につなげる。

## 2. 顧客の理解

### 2.1 発言と行動、インサイト

| 顧客 | 欲しいと言ったこと（引用） | 実際の行動・決め手（引用） | インサイト（仮説） |
| --- | --- | --- | --- |
| A | 「年代とか予算とか関係性とかを入れたら、もう少し絞ってくれたら便利だと思います」「条件を入れたら人気商品を何個か出してくれる機能ですかね」 | ランキング1位のハンドクリームは「香りが好みじゃなかったら嫌だなと思って」購入せず。夜に3商品まで絞り、同僚2人の LINE グループで「この3つならどれがいい？」と相談。「二人が『それならいいと思う』と言ってくれたのは大きかったです」 | 欲しいのは候補を絞ることよりも、相手の好みが分からない中で「これならよい」と確信できる根拠（一緒に贈る同僚の同意）ではないか。自分だけでは選択に確信を持てないのではないか。 |
| B | 「予算で絞れるのが一番大事ですね」 | 3,000〜5,000円で約30商品を見たが購入せず。人気ランキングは「友達にあげるには逆に普通すぎる」。Instagram で見つけた 5,800円の卓上ライトを「絶対あの子が好きそうだと思って」Giftia で購入。 | 予算・人気を軸にした探し方では、友人の個性に合う商品が見つけにくいのではないか。商品は Giftia にあったのにサイト内では見つけられず、SNS で見つけている。相手に合うと感じた商品には予算を超えて支払っている。 |
| C | 「相手の好みに合うものをおすすめしてもらえると、一番いいですよね」 | 会社宛て配送・常温保存・個包装・賞味期限を何度も確認し、有名店の個包装の焼き菓子を購入。「これなら受け取って困ることはないかなと思って」 | 好みが分からない相手には、好みへの適合よりも「外さないこと」が判断の中心になったのではないか。その判断に必要な情報が整理されておらず、確認に手間がかかっているのではないか。 |
| D | 「母くらいの年代で人気のものが分かると助かります」 | ランキング上位を見ても決められず、その日は購入せず。数日後、母が以前「こういうの便利そうね」と話していたことを思い出し、ランキング外の小型電気ケトルを購入。「これなら使ってくれるかなと思って」 | 手掛かりがないため人気を入口にしたが、決め手は母本人の過去の発言や生活に結び付く情報だったのではないか。一般的な人気だけでは「使ってくれるか」を判断できないのではないか。 |
| E | 「去年と同じものが、期日までに確実に届けばそれで十分です」新しい商品の提案は「うーん、いらないですね」 | 前年の注文履歴を開き、同じ商品をそのまま購入。商品の比較やランキングの閲覧はしなかった。 | 新しい商品選びより、同じ贈答を手間なく確実に再現できることが重要ではないか。同一商品の欠品・終売時には代替選びが課題になる可能性がある。 |

### 3.2 採用した顧客課題と、選ばなかった候補

| 項目 | 内容 |
| --- | --- |
| 採用した顧客課題 | 相手に合う贈り物を選びたいのに、自分だけでは判断材料が足りず、第三者の後押しがないと購入を決めにくいのではないか |

| 選ばなかった理由 | Dは相手の発言という直接の根拠で決定している。まずAで、情報不足と他者の後押しを切り分ける。Dを低価値とは判断しない |

## 6. 検証方法

| 項目 | 内容 |
| --- | --- |
| 見る指標 | 共同購入セッション数、共同購入の購入案件数、共同購入案件の購入率、検討開始から購入までの日数（中央値）。利用と購入が増え、購入率が上がる一方で、購入までの日数が短くなるかを確認する |
| 成功と判断する水準 | 共同購入の利用と購入案件数が増え、案件購入率が向上し、納得を維持して期間が短くなること（数値目標は4週目に決める） |
| 仮説が間違っていたと判断する条件 | セッションだけ増えて購入案件や案件購入率が改善しない、期間短縮が未購入増や納得低下を伴う場合は見直す。人間の合意を AI が代替できたとは判定しない |
| 確かめ方（期間・データ） | 開始週で案件を分け、同じ期間だけ追跡。流入・期限までの残日数・参加人数等を揃え、成長と期間の関連を見る。比較検証で因果を確かめる |
